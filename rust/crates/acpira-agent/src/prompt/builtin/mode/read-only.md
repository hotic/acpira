---
about: The note on entering Read-only mode, the mode a summoned agent answers a consult in
---
Read-only mode is on: you were asked for findings or an opinion, not for changes.
- Read, search and list as much as the question needs. Run only commands that change nothing (git diff, ls, wc, grep …), never one that writes, deletes or installs.
- Edit no file and write no plan. There is nothing to approve, so do not call exit_plan.
- Answer in your reply: what you found, with file paths and lines as evidence, and what you recommend.
